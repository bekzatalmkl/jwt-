JWT аутентификациясы бар REST API

1. Жобаның мақсаты (Project Description)

Бұл жоба Java және Spring Boot технологиялары арқылы жасалған REST API болып табылады. Жобаның негізгі мақсаты — JWT (JSON Web Token) көмегімен пайдаланушыларды қауіпсіз тіркеу және авторизациялау жүйесін құру.

Жүйеде пайдаланушылардың рөлдеріне байланысты қолжетімділікті басқару, Access Token және Refresh Token пайдалану, сондай-ақ токендердің жарамдылық мерзімін тексеру қарастырылған.

2. Қолданылатын технологиялар (Technologies)

- Java
- Spring Boot
- Spring Security
- JJWT
- Maven
- REST API

3. Орнату нұсқаулығы (Installation)

Жобаны орнату және баптау нұсқаулығы практикалық бөлім аяқталғаннан кейін қосылады.

4. Қолдану мысалдары (Usage Examples)

API сұраныстарының мысалдары және Postman арқылы тестілеу нұсқаулары жоба іске асырылғаннан кейін қосылады.

5. Қауіпсіздік ескертпесі (Security)

Жоба API эндпоинттарын қорғау үшін JWT аутентификациясын пайдаланады.

- Құпиясөздерді хештеу.
- Access Token дұрыстығын тексеру.
- Refresh Token механизмін пайдалану.
- Токендердің жарамдылық мерзімін тексеру.
- Пайдаланушы рөліне байланысты қолжетімділікті басқару.
