JWT Authentication REST API

1. Project Overview

JWT Authentication REST API — Java және Spring Boot технологиялары негізінде әзірленетін қауіпсіз аутентификация және авторизация жүйесі.

Жобаның негізгі мақсаты — пайдаланушылардың жүйеге қауіпсіз тіркелуін, кіруін және жеке ресурстарға қол жеткізуін қамтамасыз ету.

Жүйеде пайдаланушыны тексеру үшін JWT (JSON Web Token) технологиясы қолданылады. Сонымен қатар, Refresh Token механизмін қорғау арқылы токендерді ұрлау және қайта пайдалану шабуылдарының алдын алу қарастырылады.

2. Research Objective

Зерттеудің мақсаты — REST API архитектурасында JWT технологиясын қолдану арқылы қауіпсіз аутентификация жүйесін құру, токендерді басқару принциптерін зерттеу және Refresh Token ұрлануы мен қайта пайдаланылуы мәселесін шешу.

3. Research Problem

Problem: Refresh Token Theft and Replay Attack

JWT аутентификация жүйесіндегі негізгі қауіптердің бірі — Refresh Token-нің ұрлануы және оны қайта пайдалану мүмкіндігі.

Егер шабуылдаушы пайдаланушының Refresh Token-ін иеленсе, ол токен арқылы жаңа Access Token алып, пайдаланушының аккаунтына рұқсатсыз қол жеткізуі мүмкін.

Қарапайым токендік жүйеде Refresh Token-нің жарамдылық мерзімі аяқталғанға дейін оны қайта пайдалану қаупі сақталуы мүмкін.

Бұл жағдай пайдаланушы деректерінің қауіпсіздігіне және жүйенің сенімділігіне қауіп төндіреді.

4. Proposed Solution

Refresh Token Rotation and Reuse Detection

Аталған мәселені шешу үшін екі қауіпсіздік механизмі ұсынылады:

1. Refresh Token Rotation

Әрбір токенді жаңарту кезінде сервер ескі Refresh Token-ді жарамсыз етіп, оның орнына жаңа токен береді. Осылайша, бір токенді қайта-қайта пайдалану мүмкіндігі шектеледі.

2. Refresh Token Reuse Detection

Егер бұрын қолданылып, жарамсыз болған Refresh Token қайта пайдаланылса, жүйе бұл әрекетті анықтайды.

Мұндай жағдайда сервер сол токендер тобына (Token Family) қатысты белсенді Refresh Token-дерді жарамсыз етеді және пайдаланушыдан жүйеге қайта кіруді талап етеді.

Қосымша қауіпсіздік үшін Refresh Token серверде хэш түрінде сақталады.

Осы шешім токен ұрланған жағдайда шабуылдаушының аккаунтқа ұзақ уақыт қол жеткізу қаупін азайтады.

5. Main Features

- User Registration — жаңа пайдаланушыларды тіркеу.
- User Login — логин және құпиясөз арқылы жүйеге кіру.
- JWT Authentication — пайдаланушыны токен арқылы тексеру.
- Role-Based Authorization — пайдаланушы рөлдеріне сәйкес қолжетімділікті басқару.
- Access Token — қорғалған ресурстарға қол жеткізу.
- Refresh Token — мерзімі аяқталған Access Token-ді жаңарту.
- Token Rotation — Refresh Token-ді әр жаңартудан кейін ауыстыру.
- Reuse Detection — бұрын қолданылған токеннің қайта пайдаланылуын анықтау.
- Token Revocation — күдікті жағдайда токендерді жарамсыз ету.
- Password Hashing — құпиясөздерді қауіпсіз хэштеу.

7. System Workflow

1. Пайдаланушы жүйеге тіркеледі.
2. Құпиясөз BCrypt алгоритмі арқылы хэштеліп сақталады.
3. Пайдаланушы логин және құпиясөз арқылы жүйеге кіреді.
4. Сервер пайдаланушының деректерін тексереді.
5. Деректер дұрыс болған жағдайда Access Token және Refresh Token жасалады.
6. Клиент қорғалған сұраныстарда Access Token жібереді.
7. Access Token мерзімі аяқталғанда Refresh Token арқылы жаңарту сұранысын жібереді.
8. Сервер ескі Refresh Token-ді жарамсыз етіп, жаңа токендер жұбын береді.
9. Егер ескі токен қайта пайдаланылса, Reuse Detection механизмі іске қосылады.
10. Жүйе тиісті Token Family-ді жарамсыз етіп, пайдаланушыдан қайта кіруді талап етеді.

8. Security Implementation

Жобада қауіпсіздікті қамтамасыз ету үшін келесі механизмдер қолданылады:

- Password Hashing — құпиясөздерді BCrypt арқылы хэштеу.
- JWT Signature Validation — токеннің цифрлық қолтаңбасын тексеру.
- Token Expiration — токендердің жарамдылық мерзімін бақылау.
- Refresh Token Rotation — токендерді әр жаңартудан кейін ауыстыру.
- Reuse Detection — бұрын пайдаланылған токенді қайта анықтау.
- Token Revocation — күдікті токендерді жарамсыз ету.
- Role-Based Access Control — пайдаланушы рөлдеріне сәйкес рұқсат беру.

9. Research Results

Зерттеу нәтижесінде JWT негізіндегі қауіпсіз аутентификация және авторизация жүйесін әзірлеу көзделеді.

Жүйе пайдаланушыларды тіркеу, авторизациялау, токендерді басқару және қорғалған ресурстарға қол жеткізу функцияларын орындайды.

Сонымен қатар, Refresh Token Rotation және Reuse Detection механизмдері арқылы токенді ұрлау және қайта пайдалану қаупін азайту шешімі қарастырылады.

Жоба барысында REST API қауіпсіздігі, JWT технологиясы және токендерді басқарудың заманауи әдістері зерттеледі.
