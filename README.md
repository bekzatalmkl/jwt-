JWT Authentication REST API

1. Project Overview

JWT Authentication REST API — Java және Spring Boot технологиялары негізінде әзірленетін қауіпсіз аутентификация және авторизация жүйесі.

Жобаның негізгі мақсаты — пайдаланушылардың жүйеге қауіпсіз тіркелуін, кіруін және жеке ресурстарға қол жеткізуін қамтамасыз ету.

Жүйеде пайдаланушыны тексеру үшін JWT (JSON Web Token) технологиясы қолданылады. Бұл технология сервер мен клиент арасындағы сұраныстардың қауіпсіздігін арттырады және пайдаланушының рұқсат деңгейін басқаруға мүмкіндік береді.

2. Research Objective

Зерттеудің мақсаты — REST API архитектурасында JWT технологиясын қолдану арқылы қауіпсіз аутентификация жүйесін құру және оның жұмыс істеу принциптерін зерттеу.

3. Main Features

- User Registration — жаңа пайдаланушыларды тіркеу.
- User Login — логин және құпиясөз арқылы жүйеге кіру.
- JWT Authentication — пайдаланушыны токен арқылы тексеру.
- Role-Based Authorization — пайдаланушылардың рөлдеріне сәйкес қолжетімділікті басқару.
- Access Token — қорғалған ресурстарға қол жеткізу.
- Refresh Token — мерзімі аяқталған Access Token-ді жаңарту.
- Token Expiration — токендердің жарамдылық мерзімін бақылау.
- Password Encryption — пайдаланушы құпиясөздерін қауіпсіз хэштеу.

4. Technologies Used

- Java
- Spring Boot
- Spring Security
- JWT (JSON Web Token)
- JJWT Library
- Maven
- REST API

5. System Workflow

1. Пайдаланушы жүйеге тіркеледі.
2. Жүйеге логин және құпиясөз арқылы кіреді.
3. Сервер пайдаланушының деректерін тексереді.
4. Деректер дұрыс болған жағдайда JWT токені жасалады.
5. Клиент әрбір қорғалған сұраныспен токенді серверге жібереді.
6. Сервер токенді тексеріп, пайдаланушыға тиісті рұқсат береді.
7. Токеннің мерзімі аяқталғанда Refresh Token арқылы жаңартылады.

6. Security

Жобада қауіпсіздікті қамтамасыз ету үшін Spring Security және JWT технологиялары пайдаланылады.

Құпиясөздер ашық түрде сақталмайды, олар қауіпсіз хэштеу алгоритмі арқылы өңделеді. Сонымен қатар, токендердің жарамдылық мерзімі бақыланып, пайдаланушылардың рөлдеріне сәйкес қолжетімділік шектеледі.

7. Research Results

Зерттеу барысында JWT аутентификациясының жұмыс істеу принциптері, REST API архитектурасындағы қолданылуы және Spring Security арқылы авторизацияны ұйымдастыру жолдары қарастырылады.

Жобаның нәтижесінде пайдаланушыларды тіркеу, жүйеге кіру, токендерді басқару және қорғалған ресурстарға қол жеткізу мүмкіндіктері бар қауіпсіз REST API жүйесін әзірлеу көзделеді.
